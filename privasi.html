Kebijakan Privasi

Terakhir diperbarui: September 2026

Privasi Anda sangat penting bagi kami. Kebijakan Privasi ini menjelaskan bagaimana ScribdAccess memperlakukan informasi saat Anda mengakses dan menggunakan situs kami.

Ringkasan Privasi: ScribdAccess tidak memerlukan pembuatan akun, tidak meminta data pribadi sensitif (seperti nama, surel, nomor telepon, atau data kartu kredit), dan tidak menyimpan riwayat penelusuran dokumen Anda di database kami.

1. Informasi yang Kami Proses

Saat Anda menggunakan fitur pembaca dokumen, situs kami hanya memproses tautan (URL) Scribd yang Anda masukkan secara lokal di peramban Anda (client-side processing) untuk mengidentifikasi ID dokumen dan menyusun tautan pratinjau.

2. Izin Papan Klip (Clipboard)

Tombol "Paste" meminta izin membaca teks dari papan klip (clipboard) peramban Anda hanya untuk mengisi otomatis kolom masukan URL. Kami tidak mengirimkan, membaca isi selain teks yang ditempelkan, ataupun merekam isi papan klip Anda ke peladen eksternal.

3. Log Server & Analisis Pengunjung

Untuk menjaga keandalan dan keamanan situs web, kami dapat menggunakan layanan analitik standar (seperti Google Analytics) yang mengumpulkan data teknis anonim, antara lain:

  • Tipe peramban dan sistem operasi perangkat.
  • Waktu dan durasi kunjungan halaman.
  • Halaman yang diakses dan tautan rujukan (referrer).

Data ini digunakan secara agregat untuk keperluan optimasi performa dan tidak dikaitkan dengan identitas pribadi individu.

4. Penggunaan Cookie

ScribdAccess sendiri tidak menggunakan cookie pelacak pribadi. Namun, layanan pihak ketiga seperti penyedia hosting (Vercel) atau skrip analitik (Google Analytics) mungkin menempatkan cookie fungsional standar untuk tujuan pemuatan aset dan keamanan jaringan. Anda dapat mengatur peramban untuk menolak semua cookie jika diinginkan.

5. Keamanan

Situs web ini dilindungi oleh enkripsi standar industri HTTPS (SSL/TLS) untuk memastikan seluruh komunikasi data antara peramban Anda dan situs web terenkripsi secara aman.

6. Hubungi Kami

Apabila Anda memiliki pertanyaan mengenai Kebijakan Privasi ini, silakan hubungi kami melalui repositori GitHub atau akun Instagram pengembang.
